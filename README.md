## ✨ Overview

A stunning, cinematic developer portfolio built with modern web technologies. Inspired by Japanese AAA game studio aesthetics — featuring immersive particle backgrounds, smooth scroll animations, and a sleek dark UI with accent highlights.

<div align="center">

| Section | Highlights |
|---------|-----------|
| **Hero** | Three.js particle field, parallax scrolling, cinematic intro |
| **About** | Animated skill bars, stats counter, responsive grid |
| **Experience** | Interactive timeline with scroll-triggered animations |
| **Achievements** | Hover-reactive cards with holographic effect |
| **Projects** | Filterable project gallery with grayscale-to-color hover |
| **Contact** | Functional contact form, linked social icons |

</div>

## 🎨 Design Philosophy

- **間 (Ma)** — Embracing negative space for visual breathing room
- **改善 (Kaizen)** — Continuous improvement in every detail
- **侘寂 (Wabi-sabi)** — Finding beauty in imperfection through grain textures and subtle noise
- **Custom Cursor** — A bespoke cursor that reacts to interactive elements
- **Smooth Scrolling** — Powered by Lenis for buttery-smooth navigation
- **Film Grain Overlay** — Cinematic texture for depth and atmosphere

## 🚀 Getting Started

### Prerequisites

- **Node.js** ≥ 18
- **npm** or **yarn**

### Installation

```bash
# Clone the repository
git clone https://github.com/ImpactG1/Mayank-Kenshin-Portfolio.git

# Navigate to the project
cd Mayank-Kenshin-Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at **http://localhost:3000**

### Build for Production

```bash
npm run build
npm run preview
```
